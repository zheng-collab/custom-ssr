2. Windows 安装 · Install on Windows

  1. 运行 SecureGateway-Setup.exe，一路“下一步”。Run the installer and click Next.
  2. 如果 Windows 提示“Windows 已保护你的电脑”，点击 更多信息 → 仍要运行。 If SmartScreen appears: More info → Run anyway.
  3. 如果提示“智能应用控制已阻止”，需要先关闭智能应用控制：Windows 安全中心 → 应用和浏览器控制 → 智能应用控制设置 → 关闭（关闭后无法再打开，这是 Windows 的设计）。 If Smart App Control blocks it: Windows Security → App & browser control → Smart App Control → Off.
  4. 打开 SecureGateway，用公司邮箱和密码登录，点击 Connect。Sign in with your company e-mail and click Connect.

3. macOS 安装 · Install on macOS

  1. 打开 .dmg，把 SecureGateway 拖到“应用程序”。Open the .dmg and drag SecureGateway to Applications.
  2. 第一次打开：在“应用程序”里 右键（或按住 Control 点击）SecureGateway → 打开 → 打开。如果仍被拦截：系统设置 → 隐私与安全性 → 仍要打开。 First launch: right-click → Open → Open, or System Settings → Privacy & Security → Open Anyway.
  3. 连接时 macOS 会要求输入一次 Mac 密码以设置系统代理。macOS asks for your Mac password once to set the system proxy.

4. 手机：Android 与 iPhone · Phones

手机不需要公司账号，用电脑版里的二维码即可连接。Phones connect from a QR code shown by the desktop app.

Android

  1. 安装 v2rayNG（下载 v2rayNG_x.x.x_arm64-v8a.apk；Google Play 也有）。 Install v2rayNG (APK from GitHub, or Google Play).
  2. 在电脑版 SecureGateway 里打开 Servers（服务器） 标签，选中服务器，点击 Share QR。没有电脑的同事可向 IT 索取二维码图片。 On the desktop app: Servers tab → select the server → Share QR. Or ask IT for the QR image.
  3. v2rayNG 右上角 ＋ → 扫描二维码（或 从剪贴板导入）。In v2rayNG: + → Scan QR code (or Import from clipboard).
  4. 点击右下角的 V 按钮连接；Android 会询问一次“允许 VPN 连接”，选择允许。 Tap the V button; allow the VPN request once.
  5. 验证：v2rayNG 里下拉刷新会显示延迟；或在浏览器打开 google.com。 Check: pull to refresh shows latency, or open google.com.

iPhone / iPad

  1. App Store 安装 Shadowrocket（付费，需要非中国大陆区 Apple ID）。Install Shadowrocket (paid, non-mainland Apple ID).
  2. 右上角 ＋ → 扫描二维码，扫电脑版 Share QR 显示的二维码。+ → Scan QR Code, scan the desktop app's Share QR.
  3. 打开顶部的开关，允许添加 VPN 配置。Turn on the switch and allow the VPN profile.

5. 登录问题 · Sign-in help

忘记密码 · Forgot password: 在登录窗口点击 Forgot password?，或直接访问 fourthzodiac.com/forgot-password。
在中国大陆登录报错 · Sign-in fails in mainland China（如 “The SSL connection could not be established”）： 在登录窗口点击 Can't connect?，粘贴 IT 提供的服务器链接（以 ss:// 开头），点击 Connect through server，然后再登录。程序会先建立 VPN 隧道，再通过隧道完成登录。 Click “Can't connect?”, paste the server link from IT, click “Connect through server”, then sign in.
没有账号 · No account yet: 请联系 IT 开通（需要 gateway.access 权限）。 Ask IT to enable your account.
SecureGateway 支持 V2Ray (VMess) 与 Shadowsocks 协议，内置 v2ray-core，无需另外安装。 源代码与所有版本：github.com/zheng-collab/custom-ssr
